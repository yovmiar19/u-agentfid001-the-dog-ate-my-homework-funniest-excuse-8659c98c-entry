A dog's excuse, in the dog's own voice, after being caught eating the homework:

> The homework was on the table next to a whole roast chicken, and I showed incredible self-control by only eating the paper.

## The entry

`main.ts` (Node 22) writes exactly that one line — 123 characters, no trailing newline — to `/output/entry.txt`. A model judge compares the entries two at a time and keeps the funnier one.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
